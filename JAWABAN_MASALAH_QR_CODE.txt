=====================================================
5. SESSION EXPIRY & LIFECYCLE
=====================================================

Session Status Flow:
--------------------
connecting → connected (setelah scan QR)
connecting → failed (jika error/timeout)
connected → disconnected (jika logout)


Timeout:
--------
- Session dalam status "connecting": Tidak expired otomatis
- QR Code expired: 60 detik (harus refresh QR)
- Session tidak di-scan: Tetap "connecting" (tidak auto-delete)
- Session expired kalau: User logout dari WhatsApp


Auto-delete:
------------
❌ TIDAK auto-delete
Session tetap ada dengan status "failed" atau "disconnected"

Untuk delete session:
DELETE /api/v1/sessions/{id}

6. WEBHOOK EVENTS ✅
=====================================================

YA! Webhook events OTOMATIS terkirim ke URL yang Anda provide!

Webhook URL Anda:
https://8a5fa0c560ec.ngrok-free.app/api/webhook/whatsapp


Events yang OTOMATIS dikirim:
------------------------------

1. ✅ connection.open
   - Trigger: QR code berhasil di-scan
   - Status session: "connecting" → "connected"

2. ✅ connection.close
   - Trigger: Session disconnected/logout
   - Status session: "connected" → "disconnected"

3. ✅ message.received
   - Trigger: Ada pesan masuk (incoming message)
   - Data: message content, sender info

4. ✅ message.sent
   - Trigger: Pesan berhasil dikirim
   - Data: message ID, status

5. ✅ message.updated
   - Trigger: Status pesan berubah (delivered, read)
   - Data: message ID, new status


Default Webhook Events:
------------------------
Saat create session, default webhook_events = ["*"]
Artinya: SEMUA events otomatis dikirim!


Webhook Payload Format:
------------------------
{
  "event": "connection.open",
  "timestamp": "2026-01-12T10:30:00Z",
  "session_id": "266cdcce-97a1-4d70-a6c5-b561b90acdfd_1768191349886",
  "data": {
    "phone_number": "6281234567890",
    "status": "connected"
  }
}


Custom Webhook Events:
-----------------------
Jika hanya ingin event tertentu, specify saat create session:

{
  "name": "my-session",
  "webhook_url": "https://8a5fa0c560ec.ngrok-free.app/api/webhook/whatsapp",
  "webhook_events": [
    "connection.*",
    "message.received",
    "message.sent"
  ]
}


Webhook Signature:
------------------
Setiap webhook include header:
X-Webhook-Signature: sha256=abc123...

Untuk verify signature:
const signature = req.headers['x-webhook-signature'];

11. CONTOH IMPLEMENTASI LENGKAP (PHP/Laravel)
=====================================================

<?php

class WhatsAppService
{
    private $apiKey = "wapi_35a798b44e8fed9075487b003bb8df8197ffb69d3805f17a379d26495de43af3";
    private $baseUrl = "http://72.62.125.132/api/v1";
    
    public function createSession($name, $webhookUrl)
    {
        $response = Http::withHeaders([
            'X-API-Key' => $this->apiKey,
        ])->post("{$this->baseUrl}/sessions", [
            'name' => $name,
            'webhook_url' => $webhookUrl
        ]);
        
        $data = $response->json();
        
        return [
            'id' => $data['data']['session']['id'],  // Database ID untuk QR
            'session_id' => $data['data']['session']['session_id'],  // Untuk send message
            'status' => $data['data']['session']['status']
        ];
    }
    
    public function getQRCode($databaseId)
    {
        // ⚠️ PENTING: Gunakan DATABASE ID, bukan session_id!
        $response = Http::withHeaders([
            'X-API-Key' => $this->apiKey,
        ])->get("{$this->baseUrl}/sessions/{$databaseId}/qr");
        
        $data = $response->json();
        
        if ($data['success']) {
            return $data['data']['qr'];  // Base64 image
        }
        
        return null;
    }
    
    public function sendMessage($sessionId, $phone, $message)
    {
        // ⚠️ Untuk send message, gunakan SESSION_ID!
        $response = Http::withHeaders([
            'X-API-Key' => $this->apiKey,
        ])->post("{$this->baseUrl}/messages/{$sessionId}/send/text", [
            'phone' => $phone . '@s.whatsapp.net',
            'message' => $message
        ]);
        
        return $response->json();
    }
}

// Usage:
$whatsapp = new WhatsAppService();

// 1. Create session
$session = $whatsapp->createSession(
    'my-session', 
    'https://8a5fa0c560ec.ngrok-free.app/api/webhook/whatsapp'
);

// 2. Get QR code (gunakan DATABASE ID!)
$qrCode = $whatsapp->getQRCode($session['id']);

// 3. Display QR
echo '<img src="' . $qrCode . '" />';

// 4. Send message (gunakan SESSION ID!)
$whatsapp->sendMessage(
    $session['session_id'],
    '6281234567890',
    'Hello!'
);

Route::post('/api/webhook/whatsapp', function (Request $request) {
    $event = $request->input('event');
    $sessionId = $request->input('session_id');
    $data = $request->input('data');
    
    // Verify signature (optional but recommended)
    $signature = $request->header('X-Webhook-Signature');
    
    Log::info("Webhook received", [
        'event' => $event,
        'session_id' => $sessionId
    ]);
    
    switch ($event) {
        case 'connection.open':
            // QR berhasil di-scan!
            $phoneNumber = $data['phone_number'];
            Log::info("Session connected: {$phoneNumber}");
            
            // Update database
            Session::where('session_id', $sessionId)
                ->update(['status' => 'connected', 'phone' => $phoneNumber]);
            break;
            
        case 'connection.close':
            // Session disconnected
            Log::info("Session disconnected");
            
            Session::where('session_id', $sessionId)
                ->update(['status' => 'disconnected']);
            break;
            
        case 'message.received':
            // Pesan masuk
            $from = $data['from'];
            $message = $data['message'];
            
            Log::info("Message from {$from}: {$message}");
            
            // Save to database or process
            break;
    }
    
    return response()->json(['status' => 'ok']);
});
