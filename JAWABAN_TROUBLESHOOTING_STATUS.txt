METHOD 2: Webhook (Real-time Sync) ✅ RECOMMENDED
--------------------------------------------------

Setup webhook handler di aplikasi Anda:

```php
// routes/api.php
Route::post('/webhook/whatsapp', function (Request $request) {
    $event = $request->input('event');
    $sessionId = $request->input('session_id');
    $data = $request->input('data');
    
    Log::info('Webhook received', [
        'event' => $event,
        'session_id' => $sessionId,
        'data' => $data
    ]);
    
    if ($event === 'connection.open') {
        // Session connected!
        DB::table('whatsapp_sessions')
            ->where('session_id', $sessionId)
            ->update([
                'status' => 'connected',
                'phone_number' => $data['phone_number'],
                'connected_at' => now()
            ]);
            
        // Broadcast ke frontend via WebSocket/Pusher
        broadcast(new SessionConnected($sessionId, $data));
    }
    
    if ($event === 'connection.close') {
        // Session disconnected
        DB::table('whatsapp_sessions')
            ->where('session_id', $sessionId)
            ->update([
                'status' => 'disconnected',
                'disconnected_at' => now()
            ]);
    }
    
    return response()->json(['status' => 'ok']);
});
```


METHOD 3: WebSocket/Pusher (Real-time UI Update)
-------------------------------------------------

Kombinasi webhook + broadcast:

1. Webhook update database
2. Laravel broadcast event ke Pusher/WebSocket
3. Frontend listen event dan auto-update UI

No polling needed! ✅
